# Rules

- **การสรุปงานและสกิล**: ทุกครั้งที่มีการแก้ไขหรืออัปเดตไฟล์ในโปรเจกต์ จะต้องสรุปการทำงานและแสดงรายชื่อสกิล/เทคนิคที่ใช้ในขั้นตอนการแก้ไขให้ผู้ใช้ทราบอย่างชัดเจนทุกครั้ง
- **รูปแบบเวอร์ชัน**: รูปแบบของการตั้งเวอร์ชันโปรแกรมคือ ปี.เดือนวัน.ชั่วโมงนาที (เช่น 2026.0704.0906)

## สกิลและเทคนิคที่จดจำไว้ (Learned Skills & Techniques)
- **File Modification**: การแก้ไขและแทรกโค้ดแบบเจาะจงจุด (multi_replace_file_content)
- **CustomTkinter UI Management**: การจัดการ State การแสดงผลของหน้าต่าง UI (เช่น ขยายเต็มจอด้วย self.state('zoomed'))
- **Windows API Integration**: การเรียกใช้โมดูล winsound พื้นฐานสำหรับการแจ้งเตือน
- **Agent Configuration**: การปรับแต่งกฎและพฤติกรรมการทำงานของตัวระบบ (AGENTS.md)
- **Standard Naming Conventions**: การตั้งชื่อมาตรฐานตามเวลาปัจจุบัน
- **PyInstaller Compilation**: ในโปรเจกต์นี้มีการใช้งาน `reportlab.graphics.barcode` ซึ่งจะดึงโมดูลย่อย (เช่น code93) เข้ามาแบบไดนามิกตอนรันไทม์ ดังนั้นหากจะใช้ PyInstaller ห้ามลืมกำหนด `--collect-all reportlab` หรือเพิ่ม `collect_all('reportlab')` ในไฟล์ .spec เด็ดขาด เพื่อป้องกันบัค ModuleNotFoundError แบบหลบใน
- **ReportLab Thai Vowel Adjustment & Tall Consonants**: การแก้ปัญหาวรรณยุกต์จมเมื่อใช้ฟอนต์ Tahoma (ไม่มี PUA) โดยเช็กเงื่อนไขให้แทรกแท็ก `<super>` เพื่อดันวรรณยุกต์ให้ลอยขึ้น ทั้งในกรณีที่วรรณยุกต์อยู่เหนือ **สระบน** (`\u0e31\u0e34\u0e35\u0e36\u0e37\u0e4d`) และเหนือ **พยัญชนะหางยาว** (`\u0e1b\u0e1d\u0e1f\u0e2c` - ป, ฝ, ฟ, ฬ) พร้อมใช้รหัส Unicode วรรณยุกต์ที่ถูกต้อง (`\u0e48-\u0e4b`)
- **Pandas Index Sequence Management**: การรีเซ็ตค่าคอลัมน์ที่เป็นลำดับ (เช่น NO) ใหม่อย่างชัดเจนหลังจากการลบข้อมูล (Delete) หรือต่อข้อมูล (Concat) โดยใช้ `list(range(1, len(df) + 1))` เพื่อรับประกันว่าเลขลำดับจะเรียงต่อเนื่องเสมอและป้องกันบัคจากการใช้คำสั่ง `range()` เพียวๆ ในระบบ Pandas เก่า
- **UI Tooltip Binding**: การผูก Event `<Enter>` และ `<Leave>` เข้ากับ Widget เพื่อเรียกคำสั่งแสดงและซ่อน Tooltip ให้ผู้ใช้เข้าใจการทำงานของปุ่มหรือข้อความได้ง่ายขึ้น
- **Relative Coordinate Positioning**: การจัดการ Layout และตำแหน่งชิ้นส่วนกราฟิกใน ReportLab Canvas (เช่น QR Code, Barcode, กรอบข้อความ) โดยใช้ตัวแปรตำแหน่งฐาน (`base_x`, `base_y`) เพื่อให้สามารถขยับกลุ่มกราฟิกทั้งหมดไปพร้อมกันได้อย่างเป็นระเบียบ
- **Dynamic Bounding & Visitor Extraction**: การใช้ `visitor_text` ของโมดูล pypdf เข้ามาช่วยค้นหาพิกัด (X, Y) ของตัวอักษรหรือคำเป้าหมายภายในไฟล์ PDF เพื่อนำค่าพิกัดเหล่านั้นมาเป็นจุดอ้างอิงในการสร้าง Overlay ได้อย่างแม่นยำ
- **Regex Extraction & String Slicing**: การใช้ Regular Expression วิเคราะห์และดึงข้อมูลที่ซ่อนอยู่ (เช่น หมายเลขอ้างอิง) หรือใช้วิธีหาจุดตัดข้อความเพื่อตัดข้อความขยะที่ปะปนมากับชื่อหรือที่อยู่ออกไป
- **Data Cleansing (Blank Handling)**: การดักจับและจัดการค่าว่าง (Empty String) ใน DataFrame ก่อนทำ Export โดยแทนที่ด้วยเครื่องหมาย `"-"` เพื่อไม่ให้เซลล์ใน Excel ว่างเปล่าจนอาจเกิดความสับสน
- **PDF Page Cropping & Bounding Box Manipulation**: การประยุกต์ใช้โมดูล `pypdf` สำหรับการตัดส่วนของหน้ากระดาษ (Crop) ในไฟล์ PDF ต้นฉบับ โดยการนำพิกัด (X, Y) ที่ค้นพบจากข้อความอ้างอิง มาคำนวณและปรับลดค่าขอบเขตของกระดาษผ่านคำสั่ง `page.mediabox.top`, `page.mediabox.bottom`, และ `page.cropbox` เพื่อดึงออกมาเฉพาะส่วนที่ต้องการ (เช่น ตัดแบบฟอร์มด้านบนทิ้งให้เหลือเฉพาะรูปจ่าหน้าซองจดหมาย) ซึ่งเป็นเทคนิคที่ช่วยคงสภาพฟอนต์ โลโก้ และการจัดรูปหน้าของไฟล์ต้นฉบับเดิมไว้ได้ 100%
- **CustomTkinter Toplevel Override**: การสร้าง Custom MessageBox ด้วย `CTkToplevel` เพื่อให้หน้าต่างแจ้งเตือนมีสไตล์ตรงกับ Theme ของแอปพลิเคชัน (รองรับ ไอคอน, ตำแหน่งกึ่งกลางหน้าจอ, และการหยุดรอผลลัพธ์จากผู้ใช้แบบ Synchronous)
- **Safe Checkbox UI Implementation**: การใช้ตัวอักษรธรรมดาและ Bracket (เช่น `[ ✓ ]` หรือ `[   ]`) แทนสัญลักษณ์ Unicode ในตาราง `Treeview` เพื่อแก้ปัญหาการแสดงผลเพี้ยน (กลายเป็น Emoji ส้ม/แดง) บน Windows บางเวอร์ชัน
- **Treeview Text Wrapping Simulation**: การใช้ Tooltip ที่ตั้งค่า `wraplength` เข้ามาช่วยแสดงผลข้อมูลในเซลล์ที่ยาวเกินไป (เช่น ที่อยู่) แบบขึ้นบรรทัดใหม่ เนื่องจาก Tkinter `Treeview` ไม่รองรับข้อความหลายบรรทัด
- **Treeview Responsive Columns**: การจัดสรรขนาดคอลัมน์ให้ตอบสนองกับขนาดหน้าจอ โดยใช้ `minwidth` ควบคู่กับการจำกัด `stretch=True` เฉพาะคอลัมน์ที่ต้องการให้ขยายตัว (เช่น ที่อยู่) เพื่อไม่ให้คอลัมน์อื่นถูกเบียดจนเสียสัดส่วน
- **Dataframe State Column Exclusion**: การกรองคอลัมน์ควบคุมสถานะ (เช่น `SELECTED`) ออกจาก Dataframe ก่อนทำการ Export ด้วยคำสั่ง `.drop(columns=[...])` เพื่อรักษาโครงสร้างไฟล์ปลายทางให้สะอาด
